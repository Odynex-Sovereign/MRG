Security & data handling

Accurate posture — no unsupported certifications claimed.

What we process

Account details you provide, simulation choices, optional feedback, and standard technical logs (IP, user agent) for reliability and abuse prevention.

What we do not do by default

We do not sell personal data. We do not claim SOC 2, ISO 27001, FedRAMP, or similar certifications unless a specific deployment has completed those audits under contract.

Technical controls in this product

  • Security headers (CSP, frame denial, nosniff, referrer policy)
  • Rate limiting on application routes
  • Secrets via environment / Fly secrets — never committed
  • Optional Postgres with connection via DATABASE_URL
  • Health and readiness endpoints for orchestration

Institutional deployments

Dedicated instances, data residency preferences, SSO, and audit logging can be scoped in a written agreement. See Institutional licensing.
